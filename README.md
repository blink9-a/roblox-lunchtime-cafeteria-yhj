# roblox-lunchtime-cafeteria-yhj

## 프로젝트 소개 (Project Overview)

**점심시간! 안전하게 급식실까지**는 Roblox Studio로 제작하는 학교 안전 체험 게임입니다.
플레이어는 학생이 되어 과학실에서 출발해 복도와 계단을 지나 제한 시간 안에 안전하게 급식실까지 이동합니다.
이동 중 발생하는 예상치 못한 상황과 사고를 직접 체험하면서, 서두르는 것보다 주변을 살피고 안전하게 행동하는 것이 중요하다는 것을 배우는 것을 목표로 합니다.

## 실행 방법 (How to Run)

1. GitHub에서 `.rbxl` 파일을 다운로드합니다.
2. Roblox Studio를 실행합니다.
3. 다운로드한 `.rbxl` 파일을 Roblox Studio에서 엽니다.
4. 상단의 **Play** 버튼을 눌러 게임을 실행합니다.
5. **WASD** 키로 캐릭터를 이동합니다.
6. **Space** 키로 점프합니다.
7. **E** 키로 물체와 상호작용합니다.
8. **Shift** 키를 누르면 빠르게 이동할 수 있습니다.
